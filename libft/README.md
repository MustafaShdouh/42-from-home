# Libft

## Description

This project represents my first custom C library. The goal of this activity is to recode a set of standard C library (libc) functions, as well as additional utility functions, to better understand the underlying mechanisms of memory management, string manipulation, and linked lists.By building this library, I have gained a deeper understanding of how C handles low-level operations, pointer arithmetic, and dynamic memory allocation. This library serves as a foundational tool for future projects in the 42 curriculum.

## The Library

The library consists of several categories of functions:

### Libc Functions

Standard C functions re-implemented from scratch to mimic their original behavior:
* *Memory manipulation:* memset, bzero, memcpy, memmove, memchr, memcmp
* *String manipulation:* strlen, strlcpy, strlcat, strchr, strrchr, strnstr, strncmp, strdup
* *Type conversion:* atoi
* *Character checks:* isalpha, isdigit, isalnum, isascii, isprint, toupper, tolower
* *Dynamic memory:* calloc

### Additional Functions

Utility functions that are not part of the standard libc but are useful for data management:
* *String formatting:* ft_substr, ft_strjoin, ft_strtrim, ft_split, ft_itoa, ft_strmapi, ft_striteri
* *File descriptor output:* ft_putchar_fd, ft_putstr_fd, ft_putendl_fd, ft_putnbr_fd
Functions to manipulate lists:
* ft_lstnew, ft_lstadd_front, ft_lstsize, ft_lstlast, ft_lstadd_back, ft_lstdelone, ft_lstclear, ft_lstiter, ft_lstmap

## Instructions

### 1. Compilation

To compile the library, run the following command in the root directory:```bash
make
This will generate the libft.a static library file.
Other make commands:

    make clean: Removes object files (.o).
    make fclean: Removes object files and the libft.a library.
    make re: Performs a clean re-compilation.

2. Usage
To use this library in your own code, include the header file and link the library during compilation:

    Include the header in your C file:
    C
    #include "libft.h"
    Compile your project with the library:
    Bash

    cc main.c -L. -lft -o my_program
